# UI/UX Specification
## Direction
Option B: modern enterprise workbench with SAP Fiori design principles.

## Global shell
Persistent left navigation, top bar with selected system/user, central workspace, clean status tokens, filterable tables, side panels/modals, accessible forms and clear empty/loading/error states.

## Pages
1. Dashboard — systems, assessments, recommendation distribution, recent work and failed jobs.
2. SAP Systems — destination alias, release, connection test, capability matrix and scan history.
3. Transaction Explorer — single T-Code, Excel upload later, scoped system scan later.
4. Assessments — search/filter and ownership.
5. Assessment workspace — Overview, Technical Analysis, Business Context, Requirements, Fiori Discovery, Fit-Gap, Decision and Generation.
6. Fiori Catalogue — standard apps, release/prerequisites and separate internal apps.
7. Generation Studio — app specification, model, floorplan, artifacts, versioning.
8. Validation Centre — checks, findings, remediation and approval.
9. Jobs & Audit — status, retry, failures and audit.
10. Administration — users, roles and settings.

Show summaries first and technical detail in modal/side panel. Visibly distinguish live SAP evidence, catalogue facts, AI suggestions, manual input and synthetic demo data.
