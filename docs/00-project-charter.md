# Project Charter
## Product
FioriX — SAP Fiori App Discovery, Assessment and Generation.

## Purpose
A governed workbench for assessing SAP S/4HANA transactions, discovering suitable standard Fiori apps, comparing confirmed business requirements, recommending Adopt/Extend/Build/Review, and preparing controlled custom app drafts where justified.

## Users
SAP functional consultants, ABAP developers, SAPUI5 developers, solution architects, product owners, reviewers and administrators.

## Initial scope
S/4HANA On-Premise only. ECC excluded. One pilot T-Code and one business process first. Excel and scoped system-wide scans later.

## Core principles
1. Standard SAP Fiori first.
2. Evidence-backed discovery and fit-gap.
3. Unknown is not Unsupported.
4. Technical metadata does not prove company-specific business usage.
5. AI output is advisory until reviewed.
6. Generated code is a draft; no automatic production activation or transport.

## Out of scope initially
Universal support for every T-Code, guaranteed complete runtime dependency reconstruction, arbitrary code generation, unrestricted source-code extraction, automatic production deployment, replacement of ADT or SAP Fiori Apps Reference Library.
