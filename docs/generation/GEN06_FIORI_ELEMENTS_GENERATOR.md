# GEN-06: SAP Fiori Elements Application Generator
## Technical Design, UI5 1.120.0 Baseline & Annotation Vocabulary

### 1. Scope & Generator Architecture

The **GEN-06 SAP Fiori Elements Generator** produces a fully compliant, deployable SAP Fiori Elements application consuming the OData V4 service generated by GEN-05.

Targeting **SAP S/4HANA 2023 On-Premise (FPS00)**, the application baseline specifies:
- **SAPUI5 Runtime Target:** `1.120.0` (LTS baseline for S/4HANA 2023).
- **Floorplan:** `ListReportObjectPage` (OData V4).
- **Theme:** `sap_horizon` (Morning Horizon / Fiori 4 design system).
- **Annotation Strategy:** Hybrid metadata architecture utilizing CDS Metadata Extensions (`.mde.asddls`) for business field layouts and local XML annotations (`webapp/annotations/annotations.xml`) for UI-specific presentation overrides.

### 2. Scaffolded Project Structure

The generated Fiori application structure complies with the standard SAP Fiori Tools / UI5 CLI specification:

```text
fiori/
├── package.json                   (Project dependencies & UI5 scripts)
├── ui5.yaml                       (UI5 Tooling build & server config)
├── README_FIORI.md                (Local run & testing instructions)
└── webapp/
    ├── Component.js               (UI5 Component descriptor bootstrap)
    ├── index.html                 (Local preview sandbox harness)
    ├── manifest.json              (Fiori Elements V4 App Descriptor)
    ├── annotations/
    │   └── annotations.xml        (OData V4 XML Annotations)
    └── i18n/
        └── i18n.properties        (Internationalization keys)
```

### 3. Key Component Specifications

#### 3.1 `webapp/manifest.json` (`FIORI_MANIFEST`)
- **Schema Version:** `1.59.0`
- **`sap.app`:**
  - `id`: `<namespace>.<appTitle>` (e.g., `fiorix.payment.managepayments`)
  - `dataSources`: OData V4 data source pointing to the relative service endpoint `/sap/opu/odata4/sap/zui_paymentheader_o4/srvd/sap/zui_paymentheader_o4/0001/`.
  - `annotations`: Local `annotation` reference pointing to `webapp/annotations/annotations.xml`.
- **`sap.ui5`:**
  - `dependencies.minUI5Version`: `1.120.0`
  - `routing`:
    - Root `ListReport` target using `sap.fe.templates.ListReport`.
    - ObjectPage target using `sap.fe.templates.ObjectPage` for Header entity.
    - Sub-ObjectPage target for nested child items with deep navigation.

#### 3.2 `webapp/annotations/annotations.xml` (`FIORI_ANNOTATIONS`)
- Utilizes the OASIS OData V4 EDMX format and SAP UI vocabularies (`com.sap.vocabularies.UI.v1`, `com.sap.vocabularies.Common.v1`).
- Defines:
  - `UI.SelectionFields`: Search filter bar fields derived from entity primary and semantic keys.
  - `UI.LineItem`: Columns displayed in the primary table.
  - `UI.HeaderInfo`: TypeName, Title, and Description for Object Page header.
  - `UI.Facets`: Collection facets and reference facets organizing Object Page sections.

#### 3.3 `ui5.yaml` & `package.json`
- `ui5.yaml` configures `@ui5/cli` specVersion `3.0` with `fiori-tools-proxy` routing backend requests to the S21 mock or remote system, and `fiori-tools-appreload` for live editing.
- `package.json` specifies scripts:
  - `npm start`: Runs `ui5 serve --open index.html`.
  - `npm run build`: Executes `ui5 build --clean-dest`.

### 4. Integration with GEN-05 Artifacts

The Fiori Elements generator reads the exact entity definitions, keys, and relations produced in GEN-05:
1. **Entity Set Names:** Match the CDS Projection View entity sets (e.g., `ZC_PaymentHeader` -> `PaymentHeader`).
2. **Draft Actions:** If the architecture profile has draft enabled (`MANAGED_RAP_DRAFT`), the manifest automatically configures the SAP Fiori Elements draft controller (`editFlow`), activating auto-save and draft indicators.
3. **Field Labels:** Synchronized between CDS `@EndUserText.label` and `i18n.properties`.
