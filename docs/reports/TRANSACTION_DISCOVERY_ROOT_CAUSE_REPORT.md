## Suspected Issues Requiring Live S21 Verification

1. **S21 ADT `/sap/bc/adt/vit/wb/object_type/trant/object_name/<TCODE>` XML Schema:** Whether `S21` returns `PGMNA`, `DYPNO`, and `DEVCLASS` attributes in the exact regex patterns expected by `fetchAdtTransactionDetails()` (Lines 234–247) has not been verified against live `S21` in this read-only audit.
2. **Program Package vs Transaction Package:** If a transaction (`R3TR TRAN`) resides in one package and its program (`R3TR PROG`) resides in another, `searchAdtTransaction()` only reads `adtcore:packageName` on the `TRAN` object and never queries the `PROG` object's `TADIR` entry.
