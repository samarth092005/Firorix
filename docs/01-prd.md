# Product Requirements Document
## Problem
Assessing transactions for Fiori adoption requires technical repository investigation, functional process understanding, catalogue research, release checks and fit-gap analysis across several tools and specialists.

## Goals
- Analyse standard and custom T-Codes.
- Discover technical objects and dependencies with provenance.
- Capture actual business requirements.
- Discover verified standard SAP Fiori apps.
- Perform requirement-level fit-gap.
- Recommend Adopt / Extend / Build / Review.
- Generate reviewable artifacts for supported Build cases.
- Provide validation, approval and audit.

## Main journey
Sign in → select SAP system → enter T-Code → discovery job → technical evidence → business context → confirmed requirements → standard Fiori discovery → fit-gap → recommendation → draft generation if Build → validation → approval.

## Success measures
- Coverage of pilot discovery fields with real evidence.
- Catalogue records with source and release verification.
- Requirement-level match coverage.
- Reviewer agreement with recommendation.
- Generated project validation result for supported pattern.
- Job success/failure and processing time.
- False-positive dependency rate.
