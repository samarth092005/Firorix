# Fiorify Feature Register

## Initial demo
- Authentication and role-aware navigation.
- SAP system registration and connection/capability test.
- Single T-Code assessment.
- Asynchronous discovery job.
- Transaction metadata and supported repository discovery.
- Evidence-backed technical explorer and detail modal.
- Business context and requirement capture/confirmation.
- Curated verified standard Fiori catalogue.
- Requirement-level fit-gap.
- Adopt / Extend / Build / Review decision.
- Generation specification.
- One validated draft generation pattern.
- Validation findings and developer approval.
- Assessment history and audit.

## Later releases
- Excel bulk upload.
- Permission-aware system-wide scan.
- Customer-specific Fiori catalogue.
- Semantic search/embeddings.
- AI-assisted requirement extraction.
- More app generation patterns.
- Transport readiness integration.
- Enterprise multi-system scale and operations.

## Explicitly not promised
- Complete runtime dependency graph for every T-Code.
- Automatic one-to-one T-Code-to-Fiori mapping.
- Arbitrary custom app generation.
- Automatic production activation or transport.
